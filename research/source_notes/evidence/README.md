# Рабочие свидетельства доступа

Дата: 2026-11-04. primary_access_log.json хранит URL, исходный SHA-256 полученного HTML и SHA-256 производного текстового файла. Текст получен удалением HTML-разметки; возможны остатки атрибутов, сносок и навигации. Это не новое критическое издание. Полные тексты внешних площадок не следует распространять в ZIP: часть современных редакторских вставок может сохранять авторское право. Для воспроизводимости достаточно журнала URL/хешей, реестра sources/primary_sources.md и собственных заметок primary_initial.md.

Старые переводы LacusCurtius: public domain по уведомлениям соответствующих страниц; английские переводы Paton, White, Rolfe, Edwards, Peskett, Perrin, Cary и Shipley. Hall1923 у Attalus — исторический перевод, но современные комментарии площадки не становятся public domain автоматически. Cicero Att.8.9: E. S. Shuckburgh1908–1909; электронный текст Perseus обозначен CC BY-SA3.0US. Латинский Cicero De legibus3 — Université Grenoble Alpes, атрибуция издания на самой странице требует дополнительного библиографического контроля.

Наличие файла означает доступ, а не полное прочтение; просмотренные разделы указаны в реестре.
