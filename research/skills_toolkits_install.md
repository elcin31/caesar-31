## Способ установки и зависимости

AWT рекомендует каноническое дерево `.claude/skills/`, представленное в Codex через `.agents/skills/`, либо собственный `scripts/install-codex-skills.py`, копирующий все девять навыков и при необходимости создающий частную Python-среду. Изучен код установщика; он не запускался, поскольку проекту нужны пять навыков, уникальные имена и локальная установка. Поддеревья скопированы собственным коротким скриптом на стандартной библиотеке Python; зависимости и справочные файлы сохранены. Общие имена note/map/audit/export переименованы в awt-* для исключения коллизий.

Historical Research рекомендует `codex plugin marketplace add` и `codex plugin add`; для требуемой пользователем локальной структуры вместо глобальной установки скопированы четыре совместимых навыка. Их общие `references/` сохранены локально в каждом поддереве; ссылки `../../references/` исправлены на `references/`. Никакая учётная запись или приватная база данных не подключалась.

Проверенные доступные средства: Python 3.12.14; Node.js v24.22.1; Pandoc 3.1.11.1. Текстовые навыки исполнимых зависимостей не требуют. Node.js нужен для notes-lint/count-words; базовая verify-refs.py использует стандартную библиотеку Python. Полный набор AWT для автономного конвертера заявляет PyYAML 6.0.3, python-docx 1.2.0, Markdown 3.7; альтернативный backend — pypandoc + Pandoc, а извлечение PDF — Poppler/pdftotext. В рамках установки эти пакеты не устанавливались и их присутствие не объявляется подтверждённым. Перед запуском конкретного вспомогательного скрипта необходим отдельный просмотр его кода и проверка зависимостей.

## Применение к античному Риму

Общие операции источниковедческой критики, учёта взаимозависимости текстов, различения обнаружения/получения/чтения и проверки конкурирующих объяснений применимы напрямую. Не устанавливались китайские стилистические и цитатные навыки `*-zh`: их требования к языку и примечаниям не заменяют русский научный текст и Chicago Notes and Bibliography. Китайские цифровые коллекции не принимаются за релевантную базу данных о Риме. Названия источников и их деление сверяются по конкретным античным изданиям; книга/глава/параграф заменяют фиктивную пагинацию веб-страницы.

У AWT некоторые автоматические модули рассчитаны на англоязычные диссертации и author-year ссылки; их результаты нельзя без адаптации выдавать за проверку русской монографии с постраничными примечаниями. Стилевой fingerprint требует достаточно большой и подходящей полнотекстовой базы; такой базы при установке нет, поэтому эта проверка не проводилась. Экспериментальный writing-loop не устанавливался. За точность содержания остаётся ответственным исследовательский процесс проекта.
