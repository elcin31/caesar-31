# Сборка читательской версии

Состояние инфраструктуры: 2026-11-04. Это журнал подготовки инструментов; он не заменяет журнал проверки окончательно собранной рукописи.

## Команды

Из корня проекта:

```sh
python scripts/make_cover.py
python scripts/build.py
python scripts/verify_exports.py --epubcheck-jar /tmp/caesar-tools/epubcheck-5.4.0/epubcheck.jar
```

Скрипт сборки сам находит существующие непустые `manuscript/introduction.md`, `manuscript/chapters/*.md`, `manuscript/appendices.md`, `manuscript/bibliography.md` в этом порядке. Каждый экспорт использует один набор Markdown-файлов и примечаний. `dist/build_manifest.json` содержит SHA-256 каждого исходного текста и результата, размер файлов, время сборки и версии инструментов; `dist/build.log` сохраняет предупреждения Pandoc. Повторный запуск пересобирает файлы, а не редактирует бинарные документы вручную. Двоичное совпадение разных запусков не гарантируется: ZIP-контейнеры и метаданные экспортёров содержат время создания.

## Зависимости и проверенные версии

- Pandoc 3.1.11.1: преобразование структурного Markdown в DOCX, EPUB 3 и LaTeX.
- XeTeX 0.999996, TeX Live 2025/dev/Debian: PDF с кириллицей и постраничными сносками.
- Python 3, python-docx 1.2.0: формирование эталонных стилей DOCX и полей колонтитулов.
- Pillow 13.0.0: только воспроизводимая типографическая обложка.
- DejaVu Serif / DejaVu Sans / DejaVu Sans Mono: установленные системные шрифты с кириллицей; PDF встраивает используемые подмножества. EPUB не встраивает шрифты и позволяет читалке выбрать гарнитуру.
- Java и официальный EPUBCheck 5.4.0: полная формальная проверка EPUB.
- Poppler `pdfinfo`, `pdftotext`, `pdftoppm`: число страниц, извлечение текста, визуальная корректура выбранных страниц.

Использованы собственные короткие скрипты проекта и установленный Pandoc. Сторонние установщики и вспомогательные скрипты из каталогов навыков не запускались. Навык `awt-export` прочитан: он предусматривает прямой вызов `/export`, поэтому его конвертер не активирован; проект использует отдельную сборку согласно явному заданию пользователя.

## Оформление и границы проверки

DOCX: поля 2,2–2,7 см, DejaVu Serif 11,5 pt, основной интервал 1,15, сноски 9 pt, книжная иерархия заголовков, титульная страница, поле автоматического оглавления, номер страницы, колонтитул. Word при открытии может запросить обновление поля оглавления; это поле, а не вручную набранные номера.

PDF: A5, книжная гарнитура DejaVu Serif, титульный лист, оглавление с действительными номерами страниц, активные ссылки, постраничные сноски. Кириллица проверяется извлечением текста; дополнительно требуется осмотр реальных страниц после окончательной сборки.

EPUB: контейнер EPUB 3, `ru-RU`, интерактивная навигация, оригинальная типографическая PNG-обложка, адаптивная CSS, связанные примечания с обратными ссылками. Все внутренние ссылки и ресурсы проверяются. EPUBCheck проверяет нормативную валидность; запуск Apple Books в этой Linux-среде недоступен, поэтому проверка в самом приложении не заявляется.

Обложка — современная типографическая работа проекта, не реконструкция античного памятника. `assets/cover.svg` — редактируемый исходник, `assets/cover.png` — растровый ресурс EPUB; воспроизводится `scripts/make_cover.py`. Обложка не содержит чужих фотографий. Шрифты используются как системная зависимость; отдельные файлы шрифтов в EPUB и архив проекта не копируются.

## Техническая проба

Сборка короткого служебного текста из `/tmp` проверила все три формата, русскую типографику, реальную сноску DOCX/PDF, пару ссылок EPUB и поле оглавления. Ошибка пустого `dc:date` при первом тесте устранена: дата теперь задаётся стандартной ISO-строкой `2026-11-04`. Повторная проба прошла EPUBCheck без ошибок. Служебные выходные файлы удалены до передачи инфраструктуры; они не являются главами монографии.

## Окончательная сборка 5 ноября 2026 г.

Фактическая версия 0.1 собрана и проверена; полный результат — `research/export_review.md`. В системном формате XeLaTeX отсутствовали русские переносы. Теперь сборщик автоматически создаёт изолированный формат с английскими и русскими шаблонами в `.cache/`, используя два неизменённых файла в `scripts/tex-support/`. Их происхождение, лицензия LPPL и контрольные суммы включены в дистрибутив; кэш не включается и воспроизводится стандартным `fmtutil-user`. Системная конфигурация не меняется. Требуется наличие `fmtutil-user`/`mktexlsr` из TeX Live. При обновлении движка или шаблонов формат пересоздаётся.

PDF: заголовки уменьшены до подходящего A5 кегля; изображения закреплены по месту; голые DOI обрабатываются как активные переносимые ссылки. Исходник не содержит добавленных скрытых переносов. Проверка дополнительно сопоставляет сноски с AST исходного Markdown, проверяет сохранность изображений и хеши ресурсов, встраивание PDF-шрифтов и границы каждого слова. Окончательный PDF содержит 42 страницы; EPUBCheck завершён без ошибок и предупреждений. Отдельный журнал XeLaTeX показывает 0 Overfull и 123 некритических Underfull; подробности и пределы проверки сохранены в отчёте.
