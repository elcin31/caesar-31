# Реестр иллюстраций и прав

Проверка: 4 ноября 2026 г. Поле «загружено» означает наличие файла в assets, но само по себе не означает включения в сборку рукописи. Финальное включение проверяется по экспортам. Изображения не ретушировались и не реконструировались; скачаны музейные версии web-large. Для печати крупным форматом потребуется загрузить оригиналы по сохранённым API-ссылкам. Не следует принимать музейную идентификацию портрета за доказанную биометрическую внешность исторического лица.

## Допущено к использованию

### IMG-01. Серебряный денарий Октавия (Августа), аверс

- Оригинальное название: *Silver denarius of Octavian (Augustus)*.
- Атрибуция: римская чеканка; мастер не указан. Музей указывает Рим или Брундизий. Атрибуцию монетного двора не уточняем сверх каталога.
- Датировка: около 29–27 гг. до н. э. (`objectDate` API и объектная страница). Числовые интервалы `objectBeginDate/objectEndDate` в API огрублены и отличаются от текстовой даты; в подписи применена именно каталожная текстовая дата.
- Материал: серебро; музейная масса 3,8 г.
- Коллекция: The Metropolitan Museum of Art, New York; Rogers Fund, 1908.
- Инвентарный номер: **08.170.89**; objectID **248037**.
- Объектная страница: <https://www.metmuseum.org/art/collection/search/248037>.
- API: <https://collectionapi.metmuseum.org/public/collection/v1/objects/248037>.
- Изображение: <https://images.metmuseum.org/CRDImages/gr/web-large/LC-08_170_89b.jpg>.
- Правовой статус: страница маркирует изображение **Public Domain**, API `isPublicDomain=true`. Политика [Open Access at The Met](https://www.metmuseum.org/hubs/open-access) разрешает неограниченное коммерческое и некоммерческое использование музейных изображений общественного достояния по **CC0**; текст [CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/).
- Локальный файл: `assets/images/met_248037.jpg`, 599 × 504 px. Скачан и визуально просмотрен: показан профильный портрет на аверсе; реверс здесь не воспроизведён. Содержание музейного описания реверса не следует выдавать за видимое на этом файле.
- Рекомендуемая подпись: «Серебряный денарий Октавия, аверс. Около 29–27 гг. до н. э. The Metropolitan Museum of Art, New York, Rogers Fund, 1908, 08.170.89. Public Domain / CC0».
- Снимок API-метаданных: `assets/provenance/met_248037.json`.

### IMG-02. Мраморный портрет императора Августа

- Оригинальное название: *Marble portrait of the emperor Augustus*.
- Атрибуция: римская скульптура; неизвестный мастер. Это портретная голова, а не сохранившийся полный бюст.
- Датировка: около **14–37 гг. н. э.**; музей относит произведение к раннеимператорскому, Юлиево-Клавдиевскому периоду. В подписи нельзя называть предмет бесспорно прижизненным изображением Августа.
- Материал: мрамор; высота по каталогу 27,9 см.
- Коллекция: The Metropolitan Museum of Art, New York; Rogers Fund, 1908.
- Инвентарный номер: **08.258.47**; objectID **248119**.
- Объектная страница: <https://www.metmuseum.org/art/collection/search/248119>.
- API: <https://collectionapi.metmuseum.org/public/collection/v1/objects/248119>.
- Изображение: <https://images.metmuseum.org/CRDImages/gr/web-large/DP331249.jpg>.
- Правовой статус: **Public Domain**, API `isPublicDomain=true`, музейная политика **CC0** по ссылкам IMG-01.
- Локальный файл: `assets/images/met_248119.jpg`, 468 × 624 px; скачан и визуально просмотрен. Музейная подставка видна на снимке; она не часть античного портрета.
- Рекомендуемая подпись: «Мраморная портретная голова Августа. Около 14–37 гг. н. э. The Metropolitan Museum of Art, New York, Rogers Fund, 1908, 08.258.47. Public Domain / CC0».
- Снимок API-метаданных: `assets/provenance/met_248119.json`.

### SCH-01. Родственная связь Цезаря и Октавия

- Тип: **современная схема**, созданная для проекта в 2026 г.; не античный артефакт и не полная генеалогия Юлиев-Клавдиев.
- Файлы: `assets/genealogy.svg` (редактируемый источник) и `assets/genealogy.png` (1650 × 1050 px).
- Источники: Светоний, *Божественный Август* 4.1 (Юлия — сестра Цезаря, мать Атии; Атия — мать Октавия); 7.2 (имя Гай Цезарь по завещанию); 8.2 (принятие наследства); *Божественный Юлий* 83.2 (завещательное усыновление и передача имени).
- Проверенное издание: Suetonius, *The Lives of the Caesars*, trans. J. C. Rolfe, Loeb Classical Library, 1913; электронное воспроизведение LacusCurtius, Bill Thayer: [Augustus](https://penelope.uchicago.edu/Thayer/E/Roman/Texts/Suetonius/12Caesars/Augustus*.html), [Julius](https://penelope.uchicago.edu/Thayer/E/Roman/Texts/Suetonius/12Caesars/Julius*.html). Названные разделы непосредственно просмотрены.
- Методологическое ограничение: схема передаёт родственные отношения по поздней античной биографии. Пунктир отделяет усыновление от кровного родства. Юридические стадии оформления усыновления и передача политической власти не изображены. Никакой автоматической передачи государственной должности схема не предполагает.
- Даты рождения и смерти исключены: для смысловой задачи они не нужны, отдельной генеалогической проверки здесь не проводилось.
- Правовой статус графического оформления: собственная схема проекта, подготовленная с ИИ; сторонние изображения и встроенные шрифты отсутствуют. Свободное воспроизведение в составе проекта. Использован системный DejaVu Sans через SVG-ссылку на семейство, шрифт в SVG не встроен.
- Проверка: SVG разобран XML-парсером; PNG отрисован Inkscape, открыт и визуально проверен; подписи читаются и не обрезаны.
- Рекомендуемая подпись: «Родственная связь Цезаря и Октавия. Современная схема по Suet. Aug. 4.1; 7.2; 8.2; Iul. 83.2. Пунктиром показано завещательное усыновление; правовые стадии его оформления опущены».

## Технический журнал

- Cleveland Open Access API ответил HTTP 403 на запросы по Augustus и denarius; обход ограничений не предпринимался. Выбран доступный официальный API Met.
- Met API поиска ответил HTTP 410; индивидуальные endpoints 248037 и 248119 доступны и использованы. При воспроизведении загрузки обращаться непосредственно к сохранённым objectID.
- Снимки музейных JSON сохранены без ручного изменения. Контрольные суммы и размеры файлов находятся в `assets/provenance/files_manifest.json`.
- Файлы IMG-01 и IMG-02 проверены Pillow `Image.verify()` и открыты для визуального просмотра. Изображения с неизвестными правами не добавлялись.
