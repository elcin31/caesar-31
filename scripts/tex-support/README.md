# Русские переносы в изолированной сборке XeLaTeX

Системный формат XeLaTeX этой среды содержит только английские переносы. Сборщик создаёт собственный формат в `.cache/texmf-var/`, используя локальный `language.dat`; системные каталоги и домашняя конфигурация пользователя не меняются. Кэш не нужен для переноса проекта и не включается в архив: `python scripts/build.py` создаёт его заново посредством стандартного `fmtutil-user --byfmt xelatex`.

Требуются установленные XeTeX, LaTeX, Babel, `fmtutil-user` и `mktexlsr` из TeX Live. В проверенной среде это TeX Live 2025/dev/Debian. При изменении версии XeTeX или файлов переноса кэш пересоздаётся автоматически.

## Неизменённые внешние файлы

Получены 5 ноября 2026 г. из официального архива TeX Live 2025:

`https://ftp.math.utah.edu/pub/tex/historic/systems/texlive/2025/tlnet-final`

- `tex/generic/hyphenation/hyph-ru.tex`: шаблоны Александра И. Лебедева, версия 2003/03/10; пакет `hyphen-russian`, revision **73410**. Copyright 1999–2003 Alexander I. Lebedev. LPPL 1.2 или последующая версия. SHA-256: `ce988fcc66e5e29d7474df5ab5b489d3f52a50ebccf570997f992d84221b922a`.
- `tex/generic/hyphenation/loadhyph-ru.tex`: стандартный загрузчик TeX Users Group, Copyright 2008–2025; встроенное разрешение на свободное использование, изменение и распространение. SHA-256: `8d59a50b003ef646b4a38645802a7e4db55bb8f84e2f85a5a118c7049d186fe9`.

Полный исходный дистрибутив доступен в том же архиве TeX Live (`archive/hyphen-russian.tar.xz`, `archive/hyph-utf8.tar.xz`), сведения о проекте: <https://hyphenation.org/tex>. Лицензия LPPL 1.3c сохранена как `LPPL-1.3c.txt`, получена с <https://www.latex-project.org/lppl/lppl-1-3c.txt>. Уведомления правообладателей сохранены в самих файлах. Локальный `language.dat` — собственная конфигурация проекта: английский и русский, без изменения внешних шаблонов.

Установка через `tlmgr` в `/tmp` получила три небольших пакета (`hyph-utf8`, `hyphen-russian`, `ruhyphen`). Автоматическое обновление системного `language.dat` завершилось отказом в записи. Для сборки взяты только два нужных UTF-8-файла и создана указанная выше локальная конфигурация. Старые восьмибитные шаблоны и посторонние языки не включены. У репозитория TeX Live отмечена действительная подпись с истёкшим ключом; версии и SHA-256 конкретных файлов зафиксированы, изменение проверки TLS не применялось.

Это типографические шаблоны: они не вставляют скрытые символы в исходную рукопись и не изменяют её формулировки. В PDF XeTeX формирует обычные переносы строк. Для английского слова `Correspondence` в библиографии в заголовке LaTeX задана отдельная явная типографическая разбивка; текст исходника остаётся прежним.
