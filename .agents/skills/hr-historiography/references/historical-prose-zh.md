# 中文史学论述与引文保真

用于历史论文的生成、续写、返修、摘要、结语及说明性注释。正式文稿中的每句话都须叙述事实、解释关系、比较差异、承接材料或提出有据判断。

## 论述习惯与模型常见失误

| 写作位置 | 模型常见失误 | 史学写法及修订动作 |
|---|---|---|
| 提出问题 | 先报研究计划，再反复解释本文不研究什么 | 从具体对象、已有认识和需要解释的差异进入；研究范围直接交代时地及对象 |
| 句子主干 | 机制、网络、知识等抽象名词充当万能主语 | 明确人物、机构、材料及动作，说明谁安排、观察、记载或改变了什么 |
| 时间与身份 | 背景堆在开头，后面另起短句重新开讲 | 时间、地点和身份紧贴有关动作；有助于断代、归因或比较的背景才展开 |
| 引史之后 | 这条材料说明了某种差异，但不解释差异怎样发生 | 解释文字所指、事件前后、行动后果及材料之间的关系，再提出判断 |
| 段首 | 先用一句短句预告主题，下一句才真正进入材料 | 判断句、人物、时间或材料均可开段；只报题且没有新增内容的句子删去或合并 |
| 段末 | 每段都总结，上节结尾、下节开头及结语再次重复 | 判断在证据最合适的位置完成；结束于动作、比较或推论，不机械附加回收 |
| 短句 | 为显得有力而制造格言，或把句子一律拉长 | 保留具体事实和实质判断；合并提示、同义复述及对称排队的短句 |
| 长句 | 多个对象和抽象层次用分号硬连接 | 同一行动的条件、原因和后果可共用主语；转换时间、对象或完整判断时重起句子 |
| 标点 | 用分号代替尚未弄清的句间关系 | 先判先后、因果、转折、补充或并列，再选标点；分号用于内部已有停顿的同层比较 |
| 用词 | 相连、不同、安排、形成等词反复出现，却无具体对象 | 用设立、移驻、编入、询问、采集、接待、搬运、整理、刊布等已有材料支持的动作 |
| 下结论 | 不断声明不能、未必、不意味着，以回避一个已经能成立的判断 | 在材料支持的实际范围内明确下结论；解释缺口改变结论时，就地缩小或撤回该命题 |
| 说明性注释 | 写成证据配置表，告诉读者本注负责什么、还要怎么核 | 补来源、版本、词义、异文或具体事实；检索、待核、计证和流程状态留在工作记录 |

这些是按问题和材料组织论述的操作，不是每段固定模板。篇章可以按时间、空间、对象关系或问题层次展开；段首不强制观点句，段末不强制总结，标点与句长不设配额。

## 防御句的句级判别

1. 找出句子所修饰的具体事实或论断。若它只有“不能简单认为”“需要谨慎”“不足以穷尽”“本文并不是”等自我辩护，而没有影响当前判断的实际内容，直接删去。
2. 若它交代真实条件、未获、失败、缺失或版本差异，保留历史信息，紧贴相应事实写清一次。不能把未见记载写成不存在，也不能把一地一时扩大为全部。
3. 若材料能直接或经明确的桥接推理支持一个最小成立的判断，就写出判断；无需先穷尽全部材料、排除所有可能性或回应假想审稿人。
4. 若反证确实改变当前命题，调整命题及其适用范围；反证和来源批判直接参与论证。检索穷尽程度、内部淘汰方向、审计状态不进入正文。
5. 一条真实条件已经在有关事实处说明后，不在段末、节末和结语重新为同一判断辩护。论文正文与答辩信分别写作；答辩只回应实际提出的意见。

## 姓名、术语与引注

- 可确认的外国人物首次用“中文名（外文名）”，后文通常用中文名；姓名对照依据及异写有必要时放在相应注释。
- 中文姓名不能只凭拼音、音近或搜索摘要猜配。外文书目的著者、题名和出版信息按目标体例保留原文著录。
- 引文、译文、年代、数量、专名和来源元数据分别保护。说明性注释的论述文字可以在授权范围内返修，不能因此改变书目、页码、档号或直接引文。
- 首次引证、再次引证、合注和说明性注释按目标体例与具体功能安排，不机械省注，也不为同一事实重复计证。核页状态留在工作记录。
- 脚注紧跟实际承载的句段。区分活动日期、成文日期和刊布日期，区分原印页与数字页，区分旅行全程及其中一段。

## 引用保真的技术分工

**程序检查精确项，作者判断命题。** 文件能打开、数字或限定词计数相同、脚注数量正确，都不能单独证明史实、归因、因果和语义范围保持。

1. 保存输入副本，记录文稿版本与受保护的具体文字。直接引文及核定译文、出处的书目和页码、图表数据及来源是精确项；谨慎词所附着的命题是语义项。
2. 记录原书页、数字页及必要上下文，核读原页。题名页核验、引文核页、格式统一与论断支持分别记状态。
3. 把纯防御句、报题句、重复总结与真实史料限定分开。删除自我辩护不用再加另一套缓冲句；真实限定必须随命题保留，不能依靠词频决定删留。
4. 对授权的说明性注释返修，记录该注原文、新文、理由及须保持的出处文字。核页后订正姓名、页码或版本时，另记录具体来源和定位；不把普通润色授权扩大为引用改造。
5. DOCX核对真实脚注定义与正文引用、注释身份与次序、受保护出处、图表和媒体；按规范检查编号是否每页重启，并渲染页图核看注码与正文的关系。显示编号可以重排，来源身份必须能追溯。
6. diff指出确切变化；技术结果只报告检查过的项。对事实、命题范围和引用所支持语句另作语义复核；不把技术 `valid` 当作学术通过。

插件的 [DOCX检查脚本](../scripts/guard_historical_revision.py) 支持逐注记录允许改动的解释文字，且保持指定的出处不变；[保护清单](../assets/templates/revision_protection.json) 给出字段。未记录的脚注变化、出处变化、未定义引用或字面保护项变化仍会报错。新增中外姓名或删除纯防御句产生的字面差异，应按授权和实际命题复核，而不是恢复全部旧句。

逐注记录有三种用途：`explanatory_prose`记录说明文字改动和完整受保护出处；`verified_source_correction`记录原页核定后的来源订正及具体定位；`format_only`记录不变的前后来源元数据、显示格式和实际阅读状态。只按现成注释统一格式时可记`FORMAT_ONLY_USER_SUPPLIED`，不冒充核页。记录须与实际原注、新注逐字相符，声明的元数据和核页状态仍由来源复核；脚本不替作者证明这些声明。

## 交付前再读一遍

核看删句以后是否留下悬空的“则”“又”“因此”或前后者指代，材料与判断是否仍相接，同一事实是否在多个位置完整重讲。句子没有实际论述作用就删，已经自然且有作用的句段保留。工作记录、差异清单和核验结论单独交付，不混入正式稿。
