# CAESAR & AUGUSTUS

«Юлий Цезарь и Октавиан Август: две политические биографии и рождение Римской империи». Подзаголовок: «От кризиса Республики к установлению принципата».

Канонический репозиторий: https://github.com/elcin31/caesar-31, ветка `main`. Полная исследовательская рукопись v0.3:16глав, введение, заключение и приложения. Основной текст —48837русскихслов с заголовками, без примечаний, приложений и библиографии. Главы имеют внутренние научно-редакторские отчёты; выполняется полная издательская сборка и проверка. До её закрытия книга не объявляется FINAL.

Перед продолжением читать [AGENTS.md](AGENTS.md), [PROJECT_STATUS.md](PROJECT_STATUS.md) и [NEXT_ACTION.md](NEXT_ACTION.md). Не начинать исследование заново и не удалять ранее написанное.

## Материалы

- `manuscript/` — основной текст, приложения, библиография и метаданные; `research/drafts/` — сохранённые главы, ожидающие центральной интеграции.
- `research/source_notes/`, `research/claim_ledger.md`, `research/claims_ch*.md`, `research/reviews/` — чтение, доказательные связи и научно-редакторские проверки.
- `references.bib`, `sources/` — библиографическая база и реестры доступа. FULL/PARTIAL/META описывают фактически проверенный материал; полная запись не означает чтения всей книги.
- `assets/` — обложка, открытые музейные фотографии, генеалогия, три современные карты, подписи и лицензии. Карты воспроизводятся офлайн по сохранённым открытым геоданным.
- `.agents/skills/` —17 ранее установленных навыков с уникальными именами, версиями и зависимостями. Установка проверена; переустанавливать без причины не требуется.

## Сборка и проверка

Нужны Python3, Pandoc, XeLaTeX/TeX Live, шрифты DejaVu, Java, Poppler (`pdfinfo`, `pdftotext`, `pdffonts`) и зависимости из `requirements.txt`. Для запуска проверенных инструментов использовать официальные поставки; непроверенные сторонние скрипты не исполнять.

```sh
python -m pip install -r requirements.txt
python scripts/audit_project.py
python scripts/build.py --version 0.3
python scripts/verify_exports.py --version 0.3 --epubcheck-jar /path/to/epubcheck.jar
python scripts/package_release.py --version 0.3
```

EPUBCheck5.4.0: https://github.com/w3c/epubcheck/releases/tag/v5.4.0. Его JAR и системные шрифты не распространяются в проекте. Без фактического EPUBCheck результат не объявляется полной валидацией. DOCX содержит автоматическое поле оглавления, которое может потребовать обновления в Word. Прямое тестирование Apple Books в Linux не заявляется.

## Права и прозрачность

Рукопись подготовлена с применением ИИ. Внутренние проверки разными исполнителями не заменяют внешнюю профессиональную рецензию. Прочитанные страницы и библиографические записи учитываются отдельно; ни одна исходная современная монография не выдаётся за прочитанную целиком.

Сторонние навыки и материалы сохраняют собственные условия; единая лицензия MIT всему проекту не присваивается. Для двух навыков `paper-deep-research` и `paper-reviewer-check` README автора разрешает копирование при установке, общая лицензия дальнейшего распространения отсутствует. Полная установленная рабочая структура сохраняется по прямой директиве миграции; в распространяемые книжные ZIP эти два каталога не включаются, ссылки и точные SHA сохранены. Остальные навыки имеют собственные лицензии и уведомления. См. `research/skills_core_install.md` и `research/skills_toolkits_install.md`.

Met — Public Domain/CC0; Natural Earth — Public Domain; координаты Pleiades —CCBY3.0 с полными атрибуциями. История и права изображений: `assets/image_register.md`, `assets/maps_register.md`, `assets/maps/maps_provenance.json`. Фото Августа датировано около14–37н.э., а не названо бесспорно прижизненным. Типографическая обложка и схемы — современные работы проекта. Защищённые полные внешние PDF/транскрипции, токены и временные кэши не переносятся.

Первоначальная локальная история сохранена и объединяется с существующей историей `caesar-31` без force push. Отчёт о фактическом переносе и проверке целостности: `research/migration/`.
