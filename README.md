## Сборка

Исходники хранятся в Markdown; DOCX не является единственным источником текста. Используются Pandoc, XeLaTeX, Python3, python-docx и системные шрифты DejaVu. Для повторного создания обложки нужен Pillow. Проверенные версии перечислены в [журнале сборки](research/build_notes.md).

```sh
python scripts/audit_project.py
python scripts/build.py
python scripts/verify_exports.py --epubcheck-jar /path/to/epubcheck.jar
python scripts/package_release.py
```

Официальный [EPUBCheck 5.4.0](https://github.com/w3c/epubcheck/releases/tag/v5.4.0) устанавливается отдельно; его JAR не входит в архив. Если валидатора нет, структурная проверка запускается без аргумента, но EPUBCheck тогда честно получает статус `not_run`. В текущей среде путь к нему: `/tmp/caesar-tools/epubcheck-5.4.0/epubcheck.jar`.

Результаты: `dist/Caesar_Augustus_v0.1.docx`, `.epub`, `.pdf`; общий архив `dist/Caesar_Augustus_Research_v0.1.zip`. Оглавление DOCX является автоматическим полем с включённым обновлением при открытии; Word может запросить его обновление. PDF имеет уже рассчитанные номера. EPUB соответствует EPUB3; непосредственный запуск Apple Books в этой Linux-среде не проводился.

Сборка воспроизводит содержание и структуру. Побайтовая идентичность экспортов не гарантируется из-за служебных временных метаданных. Манифесты сохраняют контрольные суммы использованного текста и полученных файлов; изменение источников после сборки выявляется проверкой.

## Навыки и права

В `.agents/skills/` локально установлены 17 выбранных навыков, а не целые коллекции. Проверены пути, лицензии, зависимости и уникальность имён; версии закреплены SHA коммитов. Отчёты: [основной набор](research/skills_core_install.md) и [дополнительные комплекты](research/skills_toolkits_install.md). Сторонние скрипты навыков не запускались. Две реализации `humanizer` имеют разные имена; автоматическое обновление каталога интерфейса не предполагается, инструкции применялись через чтение `SKILL.md`.

Для `paper-deep-research` и `paper-reviewer-check` README автора разрешает копирование при установке, но общая лицензия распространения отсутствует. Они установлены в локальном рабочем репозитории, а их исходные каталоги исключены из распространяемого ZIP; ссылки и точные SHA сохранены. Остальные навыки включены со своими лицензиями и уведомлениями.

Музейные изображения Met имеют Public Domain/CC0, современная схема родства и типографическая обложка созданы для проекта. Атрибуции, датировки и правовой статус: [assets/image_register.md](assets/image_register.md). Фото Августа относится к периоду около 14–37 гг. н. э., а не объявляется прижизненным. Карты и фотографии с непроверенными правами в издание не включены. Системные шрифты не распространяются отдельными файлами; PDF встраивает подмножества согласно лицензии DejaVu.

Полные внешние транскрипции из рабочих snapshots и чужие защищённые PDF не входят в ZIP и Git-коммит; сохранены собственные заметки и журналы доступа. Нельзя объявлять весь проект единой лицензией MIT: сторонние навыки и материалы сохраняют собственные условия. Это рабочая авторская рукопись без выданной общей открытой лицензии на её дальнейшее распространение.

В исходной среде не было существующего репозитория: создан только локальный Git в `/workspace/caesar-augustus`. Репозиторий GitHub не создавался, удалённая публикация не выполнялась.
